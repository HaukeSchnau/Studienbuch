# Migration Documentation

This folder tracks active and historical migration workstreams.

- `architecture-refactor-execution-plan.md`: detailed refactor backlog and execution slices.
- `effect-local-first-plan.md`: strategic migration plan for Effect + local-first architecture.
- `effect-local-first-progress.md`: progress log and verification history.
- `web-migration-tracker.md`: WS-00..WS-09 control-plane tracker for `@stu/nextjs` -> `@stu/web`.
- `web-cutover-runbook.md`: operational cutover, verification, rollback, and cleanup runbook.

These files are intentionally detailed and operational; architecture snapshots live in `docs/architecture/`.
