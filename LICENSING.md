Initiative. The source code is public so that anyone can read, audit, and build it. Using it to run
a school is a paid product.

einer Schule ist ein kostenpflichtiges Produkt.

## Releases

The Change Date is set per version. Each release must set the `Change Date` in [`LICENSE`](./LICENSE)
to four years after that release's publication date before the tag is cut. The Business Source
License caps the conversion at four years from first publication regardless, so leaving a stale
earlier date only gives away rights sooner than intended.
